# 服饰行业 Q4 客户监控看板

数据源：桌面 `服饰Q4客户&商品盘点*.xlsx`（自动取最新修改的一份），6 个行业 sheet：内衣 / 男装 / 女装 / 运动户外 / 箱包鞋靴 / 珠宝配饰。

## 使用

```powershell
$py = "C:\Users\johnsywang\.workbuddy\binaries\python\versions\3.14.3\python.exe"
cd C:\Users\johnsywang\CodeBuddy\20261101211411
& $py build.py                                  # 默认：桌面最新源表 + 最新「客户数据*.xlsx」，数据日期取其文件名
& $py build.py --src "<xlsx路径>" --perf "<客户数据xlsx>" --date 2026-11-01
```

产物：
- `output/客户监控看板.html`：单文件看板（数据、品类地图图片均内嵌，可直接发送）
- `output/清洗结果.xlsx`：客户盘点_清洗后 / 商品上新明细 / 数据质量清单
- `data/clean.json`：清洗中间数据

依赖：`python-calamine`（源表样式表损坏，openpyxl 无法打开，必须用 calamine 读取）、`pandas`、`Pillow`、`openpyxl`（写 Excel）。

## 清洗规则（定期清洗时按此执行，规则改动需同步更新本节）

### 1. 读表定位
- 每个 sheet：A 列以「主计客户简称」开头的行为表头第 1 行，其后 2 行为子表头（第 3 行为 季节品/常规品）。
- **按表头文字定位列**，不依赖列序号；重复的「年同比」按其左侧指标命名（全平台/视频号/ams）。
- 客户名为空的行跳过并记入数据质量清单；客户名单元格含换行/、/，时视为多个简称，第 1 个作主名，其余为别名（用于匹配消耗数据）。
- **同名客户合并**（如珠宝配饰「睿泽珠宝鉴定」出现 2 行）：空值互补，文本不同则以「；」拼接，商品取并集。
- 品类地图：sheet 内嵌图片，解析 workbook → sheet → drawing 关系取出，转 JPEG 内嵌到看板（珠宝配饰源表无图）。

### 2. 客户生意情况
- 金额（万元）：数值直接用；文本提取数字，**区间/多个数字取最大值**（`抖音20-30万`→30，`10w+`→10）。全平台 GMV 原文含「抖音」的标注“抖音口径”。
- **年同比数值口径按 sheet 自动识别**：同一 sheet 某年同比列的数值绝对值中位数 > 5 → 视为百分数（`-89.59` = -89.59%），整列 ÷100；否则为小数（`1.082` = +108.2%）。当前内衣 sheet 的 ams 年同比为百分数口径。换算后 |年同比| > 5000% 的记入需确认（如男装「贴牌王怀」AMS 年同比 `463.759`）。
- 年同比 → 小数：数值直接用；`持平/基本持平/微跌基本持平`→0；`+∞`→+∞；`增长X%`/`下滑X%`（区间取大值）→ ±X%；`去年没怎么做/没有怎么搞/挂机/基本为0`→+∞（去年基数≈0）；`100%+`→+100%；`/`、`-`、其他无法解析→空。
- 视频号占比/TR：数值直接用，文本保留原文。
- 所有文本被解析的单元格均在看板中保留原文小字，并在数据质量清单中记为「已自动解析」。

### 3. 客户人力盘点
- **adq投手情况盘点**：保留原文。
- **adq专职投手数量**（新增）：描述中**不含「独立」或「专职」→ 0**；含则按以下顺序提取数字：
  `N组独立`/`N个组是独立` → N；`ADQ N人` → N；`N个(投手)(专职)adq` → N；`N个投手专职` → N；`N人/个` → N；都没有 → 1（记入需确认）。
- **微信豆投放摸底** → 统一为「微信豆xx%，adqxx%」：
  | 原格式 | 处理 |
  |---|---|
  | `近7日，ADQ与微信豆消耗占比：A%，B%` | adq=A，豆=B |
  | `ADQ：微信豆约A:B` | adq=A，豆=B，归一化为百分比 |
  | `微信豆：ADQ=A:B` | 豆=A，adq=B |
  | `微信豆A，ADQB` / `微信豆A%，ADQB%` | 按比例归一化 |
  | `● 微信豆消耗Xw… ● ADQ消耗Yw…` | 按消耗金额（区间取大）算份额，ROI 单独保留为备注 |
  | `全ADQ` / `几乎全ADQ` / `全部adq` / `ADQ=1` / `豆子不怎么投放` | 微信豆0%，adq100% |
  | 金额缺失、仅填数字（0/1）、空 | 不计算份额，记入需确认 |

### 4. 客户类型（直接取源表「客户类型」列，`clean.py::norm_ctype`）
自 `服饰Q4客户&商品盘点 (3).xlsx` 起，源表新增「客户类型」列（表头为多行文字，按「客户类型」前缀定位），**不再根据生意数据推算**，只把不同写法归一为 4 类标准类型：

| 标准类型 | 识别规则（去掉 `1、` 等序号后） | 已出现的写法 |
|---|---|---|
| 全平台生意下跌 | 含「全平台」且含「下跌/下滑」 | 全平台生意下跌、全平台GMV下跌 |
| 视频号微信豆和adq均下跌 | 含「均下跌」，或同时含「微信豆」「adq」「下跌」 | 视频号微信豆和adq均下跌（男装表头写作「抖音涨，视频号微信豆和adq均下跌」） |
| adq被豆子挤压 | 含「挤压」 | adq被豆子挤压 |
| 视频号生意增长 | 含「视频号」且含「增长」 | 视频号生意增长 |

- 空值 → **未标注**（记入需确认）；看板默认不展示「未标注」列/卡片，只有确实存在未填写类型的客户时才自动出现，避免漏计。
- 无法归入 4 类的保留原文单独成类（记入需确认），看板自动增加该类。
- 写法被归一的，看板类型标签下展示「原文：xxx」，数据质量清单记为「已自动解析」。

### 5. 双十一目标及准备情况
- 报名情况/大场日期：原文（日期型转 `X月X日`，数字转 `X日`）。
- 库存：`是/充足`→充足，`否/不足`→不足，空→未填写。
- 日均消耗/GMV 目标：同金额规则，**区间按最大值**（`5-8w/d`→8）；为空则提示「缺少目标」。
- **双十一期间消耗序时完成度** = 10.12 至昨日累计消耗 ÷ (日均消耗目标 × 已过天数)；周期 10.12–11.15 共 35 天，已过天数 = 数据日期 − 10.12 + 1。汇总层只统计「有目标且有消耗」的客户：Σ累计消耗 ÷ Σ(目标 × 已过天数)。

### 6. 商品储备
- 每个单元格按 换行、`、` `，` `;` `/` 空格 拆分（**括号内不拆**，如 `保暖秋裤（猫人男/婷美女）` 为 1 个），`/`、`无`、空忽略。
- 名称含 `（N款）` 的计 N 个，否则计 1。
- **Q4 季节品数 / 常规品数** = 10–12 月同类型商品**按名称去重**后的款数合计（同一商品跨月持续上新只算 1 次）。
- 看板中「新」角标 = 当月出现、上月没有的商品。

## 消耗数据

### 推荐：多 sheet 客户数据（BI 导出，如 `客户数据11.1.xlsx`）

查找顺序：`--perf` 指定 > `input/` 下最新 `客户数据*.xlsx` > 桌面最新。找到后不再读下面的分文件。

| sheet（名称含关键字，不区分大小写） | 读取的列（本期 → 对比期 = 紧邻的下一列「…对比值」） | 对应看板 |
|---|---|---|
| `昨日` | 消耗(元)、有消耗广告数、全新创意唯一性ID数 → 各自的「环比对比值」 | 昨日消耗/广告数/全新创意 及环比 |
| `双十一` | 同上 → 「环比对比值」 | 双十一期间日耗/日均全新创意/有消耗广告数 及环比、序时完成度 |
| `qtd` | 消耗(元) → 「年同比对比值」 | QTD日耗 及年同比 |

- 同名列（多个「环比对比值」）按**位置**取：每个指标列的下一列即其对比值；「变化量」「变化率」两列**不使用**。
- `~` 表示该期无数据，按 0 计；`+∞` 等非数值忽略。
- 「整体对比汇总」行不计入客户，只用来核对：已匹配客户加总 ≠ 整体值时写入数据质量清单（客户全部匹配时，差异来自 BI 整体行的去重统计口径，如有消耗广告数，记为已解析）。
- 文件名中的 `M.D`（如 `11.1`）识别为数据日期，命令行 `--date` 优先。
- 盘点表中有、客户数据中没有的客户：看板显示「待补充」，并写入数据质量清单；这些客户在汇总中本期和对比期都不计入。

### 备用：分文件（放到 `input/` 目录后重跑 `build.py` 即可）

| 文件名（前缀匹配） | 内容 | 默认列名（可在 `config.py` 增加别名） |
|---|---|---|
| `昨日分客户*.csv/xlsx` | 分客户昨日 + 对比期 | 客户简称、昨日消耗、对比期消耗、昨日广告数、对比期广告数、昨日全新创意唯一性id数、对比期全新创意唯一性id数 |
| `双十一分客户*.csv/xlsx` | 分客户 10.12–昨日 + 对比期 | 客户简称、期间消耗、对比期消耗、期间有消耗广告数、对比期有消耗广告数、期间全新创意唯一性id数、对比期全新创意唯一性id数 |
| `QTD分客户*.csv/xlsx`（也可把这几列直接放进昨日文件） | 分客户 10.1–昨日 + 去年同期 | 客户简称、QTD日耗、去年同期QTD日耗；或给累计值：QTD消耗、去年同期QTD消耗 |

- 消耗默认单位为**元**，看板展示时 ÷10000 转万元（`config.COST_UNIT_DIVISOR`）。
- 客户按「主计客户简称」及别名匹配；同一客户多行自动加总；未匹配上的客户记入数据质量清单。
- **行业/客户类型汇总的环比、同比**：先分别加总本期值和对比期值，再算 Σ本期÷Σ对比期−1；不对客户环比求平均，也不使用 BI 导出的单客户变化率。
- 双十一期间日耗 = 累计消耗 ÷ 已过天数；日均全新创意数同理。
- **QTD日耗**（数据总览，位于「昨日消耗」前）：QTD = 10.1 至数据日期，天数 = 数据日期 − 10.1 + 1。优先用直接提供的日耗；只给累计消耗时按 累计 ÷ QTD天数 换算，去年同期按相同天数换算。
- **QTD日耗年同比** = Σ客户QTD日耗 ÷ Σ客户去年同期QTD日耗 − 1（同样先加总再算，不对客户同比求平均）。
