# 文胸 Top 素材 8 维度创意分析看板 V4

> 🎯 从 494 个视频里识别"头部品配方"——Top50（跑量）vs Bot100（不跑量）的系统性差异，提炼**可复制的爆款公式**

## 核心算法：T/B 比

```
T/B = (该子标签在 Top50 头部占比) / (该子标签在 Bot100 尾部占比)
```

| T/B 值 | 含义 |
|---|---|
| **> 1** | 头部偏好，越大越头部专属 🟢 |
| **< 1** | 尾部偏好，越小越尾部专属 🔴 |
| **= ∞** | 头部专属（尾部品 0%） 🟢★ |
| **接近 0** | 尾部专属 🔴↓ |
